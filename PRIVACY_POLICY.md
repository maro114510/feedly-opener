# Privacy Policy

This extension does not collect, transmit, or sell personal data.

## Data Access

The extension operates only on Feedly pages required for Read Later:

- `https://feedly.com/*`

## Data Storage

The extension stores user settings in browser storage:

- Open mode (all or count)
- Count value
- Reload preference

Settings are stored locally in the browser or synced via the browser's sync storage, depending on availability. No data is sent to external servers by this extension.

## Permissions

The extension requests the following permissions:

- `tabs`: open background tabs for saved items
- `storage`: persist user settings

## Changes

If this policy changes, the updated version will be published in this repository.
